# А19 — приватная база данных и автоматическая запись

## Что где лежит

- `iamkurakov/a19` — **публично**: интерфейс, стили, код расчётного движка, тесты. Ни исходного Excel, ни цен, ни клиентских заказов, ни токенов в нём нет.
- `iamkurakov/a19_data` — **приватно**: `models/A19_excel_model_PRIVATE.json.gz` (формулы, цены, материалы); `orders/<id>.json` (один заказ на файл); `settings/external_confirmations.json` (только вручную подтверждённые внешние значения).
- В браузере остаётся локальная копия данных на случай потери связи. Сохранение в браузере не означает успешную запись в GitHub: отдельно смотрите статус облака.

## Однократное подключение на рабочем устройстве

1. Создать на GitHub **fine-grained personal access token** (личный токен, а не токен «Идеал Потолок»).
2. Resource owner: `iamkurakov`; Repository access: **Only select repositories**, выбрать **только `a19_data`**.
3. Permissions → Repository permissions → **Contents: Read and write**. Никаких разрешений на `ideal_potolok*`, администрирование или другие репозитории не предоставлять. Срок действия токена установить минимально приемлемый; по истечении потребуется новый.
4. Открыть https://iamkurakov.github.io/a19/ → **Подключить облако**, вставить токен, нажать **Подключить и загрузить**. Входа в А19 нет: это настройка доступа браузера к приватной базе GitHub.
5. Если установлен флажок «Запомнить токен», он хранится в `localStorage` текущего браузера **в открытом виде**. Это допустимо только на доверенном персональном компьютере и несёт риск кражи через браузер или XSS. Если флажок не установлен, токен хранится в `sessionStorage` до завершения сеанса. Не использовать общие компьютеры.

После подключения модель Excel подгружается из приватного GitHub без скачивания JSON. Изменение сохранённого заказа отправляется автоматически в `orders/<id>.json` примерно через секунду; при сбое остаётся локальная очередь записи. Статус показывается в верхней панели.

## Ограничения

- GitHub Pages — публичный статический сайт. **Без разовой передачи токена в браузер он не может читать приватный репозиторий.** Постоянный общий токен нельзя встраивать в HTML/JS, даже если он замаскирован.
- Настроена **одна рабочая сессия менеджера**; при одновременной работе в нескольких браузерах возможны конфликты. Конфликт версий GitHub не перезаписывается молча. При ошибке сохраните локальную резервную копию и сверяйте версии.
- Формульная модель **не подтверждена для финального коммерческого расчёта**. В исходных данных остаются 54 исходные ошибки и 36 внешних зависимостей; неверные или неизвестные цены не заменяются нулями.
- Автозапись заказов проверена с имитацией GitHub API в браузере. В рабочем репозитории тестовые заказы не создавались. Реальная запись начнётся после ввода менеджером собственного ограниченного токена.
- Для стабильной работы компании в будущем рекомендуется серверный API с серверным секретом и авторизацией; хранение персонального PAT в браузере — временный вариант для одного менеджера.

## Контроль данных

- Проверяйте `orders/` в `a19_data` после первого сохранения.
- Делайте полную резервную копию через кнопку в интерфейсе, особенно перед импортом/восстановлением.
- Изменение модели в локальном браузере не изменяет базовую сжатую модель GitHub; индивидуальные корректировки расчёта хранятся в соответствующих заказах, подтверждённые внешние ставки — в `settings/external_confirmations.json`.
- Не используйте токены из закрытых проектов, включая «Идеал Потолок».
