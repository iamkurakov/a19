# А19 — прямая общая ссылка без сервера

Схема: `GitHub Pages a19` → браузер → `GitHub Contents API` → приватный `a19_data`.

У владельца уже есть GitHub-токен, ограниченный только репозиторием `a19_data`. Кнопка «Скопировать общую ссылку» генерирует полный адрес с токеном в `#a19=...`. Фрагмент URL не отправляется на сервер GitHub Pages. Браузер получателя извлекает ключ и выполняет GitHub-запросы непосредственно от имени этого ключа; при открытии ссылки нет отдельной формы входа. Повторно выдавать токен не требуется.

**Полная ссылка является доступом к данным.** Токен технически доступен каждому получателю ссылки, который может читать, изменять и удалять файлы репозитория в пределах прав токена, даже за пределами интерфейса. Не публиковать полную ссылку в открытых источниках, не отправлять посторонним. Для отзыва доступа нужно отозвать существующий токен GitHub — все выданные ссылки перестанут работать.

В публичном репозитории `a19` сам токен не хранится. Данные и заказы остаются в приватном `a19_data`. Вводить токен на устройствах заказчицы не требуется. **Обычный URL без фрагмента** не сможет подключить приватное хранилище на ранее не настроенном устройстве. Владелец один раз копирует и отправляет полную ссылку вместо старой.

При одновременном редактировании одного заказа возможен конфликт GitHub SHA; текущий движок показывает проблему и не затирает удалённую версию молча. Исходные ошибки Excel остаются предупреждением, суммы предварительные.

«Идеал Потолок» не меняется: его собственная схема использует зашифрованную сборку с персональными паролями. А19 использует ссылку-ключ без пароля с указанными последствиями.
