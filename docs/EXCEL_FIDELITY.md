## Подтверждённые ограничения

Приведённые проверки означают совпадение на сохранённых исходных данных. Не подтверждено полное поведение Excel по всем типам данных, пустым ячейкам, режимам оплаты и составам конструкций. Некоторые значения отсутствуют в кэше внешней книги, поэтому их невозможно восстановить достоверно без оригинала `материалы.xlsx` и контрольных заказов. Экспортируемый JSON содержит реальные коммерческие цены и должен оставаться приватным.
