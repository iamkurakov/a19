# Анализ ошибок исходной формульной модели А19

18 ноября 2026. Исходный файл Excel и цены не публикуются.

**Повторная проверка:** 4 115 формул, 4 025 успешных, 90 проблемных.

- 54 ошибки содержатся в исходном Excel (`Объём2`, `Объём3`, `Объём4`, по 18 на лист).
- 36 формул требуют недостающие ячейки внешнего справочника (34 уникальных адреса).
- Первичные ошибки: по 3 повреждённые ссылки `N10`, деление на ноль в F34 по трём группам, зависимые вычисления.
- Внешние источники: `Материалы!J393` и отдельные записи `Стоимость трудочасов!A49:B69`.

В версии 0.2 существовала ошибка интерпретатора: `SUM`/`SUBTOTAL` пропускали ошибки диапазонов, а арифметика `""` интерпретировалась как ноль. После исправления диагностика показывает все исходные ошибки.

Действующие операции: ручное заполнение подтвердённых недостающих значений внешнего справочника; сохранение расчетов одного менеджера и полная локальная резервная копия.

**Статус:** режим одного менеджера для предварительных расчётов; готовность для коммерческих КП не подтверждена без исходной внешней книги, контрольных заказов и защищённого хранилища.
