Подключение приватного облака

База А19 хранится в закрытом iamkurakov/a19_data. Владелец подключает токен один раз, затем копирует общую ссылку. Заказчица просто открывает полученную ссылку — без GitHub и паролей.

Полная ссылка — это право доступа к общей базе. У всех её получателей будут права токена на a19_data. Обычный адрес сайта без ключа не подключит базу.

Токен нужно создать в настройках GitHub, выбрать Only select repositories → a19_data, разрешить Contents → Read and write. Никогда не вставляйте токен в публичный код или сообщения.
