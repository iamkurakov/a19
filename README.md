# А19 — расчёт рекламных конструкций

Веб-сайт: https://iamkurakov.github.io/a19/

## Доступ без сервера

Приложение работает на GitHub Pages и обращается к приватному `iamkurakov/a19_data` напрямую через GitHub Contents API. Для передачи доступа владелец, у которого **уже подключён** ограниченный токен `a19_data`, нажимает **«Скопировать общую ссылку»**. Получатель просто открывает всю ссылку с фрагментом `#a19=…`, и система самостоятельно загружает расчётную модель и общие заказы. На его компьютере не требуется создавать токен или работать в GitHub.

**Обычный URL сайта без `#a19=…` не даёт доступа к приватной базе на новом устройстве.** Получатель полной ссылки фактически получает права токена на репозиторий; это модель доступа по секретной ссылке. Подробности: [LINK_ONLY.md](docs/LINK_ONLY.md).

## Расчёт и данные

Исходная модель Excel: 16 листов, 4115 формул. В текущей версии есть 54 ошибки исходного Excel и 36 отсутствующих внешних значений, поэтому расчёты предварительные. Сохраняются ручные корректировки и отдельные заказы в `a19_data/orders/`. Общая база синхронизируется при запуске, восстановлении соединения и сохранении.

Публичный `a19` содержит только статический код. Реальные цены, исходная модель и заказы остаются в приватном `a19_data`. Исходные репозитории `ideal_potolok` и `ideal_potolok_data` не изменяются.

Тесты: `node --test tests/*.test.cjs`.
