**Версия 0.1. Исследовательский прототип, не рабочая производственная система.**

## Изоляция от «Идеал Потолок»

Это **независимый проект**. Все записи, исходники, настройки и публикации А19 принадлежат исключительно `iamkurakov/a19`. Репозитории `iamkurakov/ideal_potolok` и `iamkurakov/ideal_potolok_data` — **только для чтения** и не являются источником общих данных, авторизации либо GitHub-токенов.

Никаких импортов исходных рабочих заказов, цен, сотрудников, ключей, настроек и конфиденциального контента в А19 нет. Никаких команд GitHub, изменяющих «Идеал Потолок», не запускать.

## Что работает

- Создание, редактирование, копирование и удаление расчётов, несколько рекламных объектов в заказе.
- Поля конструкции: наименование, ширина, высота, число экземпляров.
- Редактируемый каталог материалов и работ с покупной и продажной ценой.
- Расход по площади, периметру либо вручную (только простая геометрия, не производственная технология).
- Ручное переопределение количества, себестоимости и цены каждой позиции.
- Общая стоимость, скидка, дополнительные расходы, себестоимость, прибыль и маржа.
- Фиксация ставок и цен при переводе заказа в статус «Завершено».
- Предварительное коммерческое предложение на печать; экспорт/импорт резервной копии в JSON.
- Адаптивный интерфейс на основе предоставленного логотипа А19.

## Ограничения

1. Приложение работает **без серверного хранилища и без авторизации**. Все данные принадлежат конкретному браузеру (`localStorage`, ключ `a19.prototype.v1`). При очистке данных браузера они теряются. Другие менеджеры не увидят изменения.
2. Цены и позиции **не импортированы из Excel**. Каталог изначально пуст. Нулевые цены помечают расчёт неполным, печать КП блокируется.
3. Сложные формулы Excel, внешние книги материалов, раскрой, допуски, отходы, себестоимость металлокаркаса, коэффициенты категории клиента, налогообложение, накладные расходы и технологические операции ещё не перенесены.
4. Дизайн сайта `https://a19.group/` не удалось просмотреть через доступные источники во время создания версии. Текущая чёрно-белая система отталкивается от загруженного векторного логотипа и **не заявляется как точное повторение сайта**.
5. Не вводить реальные персональные данные или производственные цены в публично доступный демонстрационный компьютер. Вводить данные допустимо лишь локально для тестов; нельзя считать это резервным хранением.

## Локальный запуск

Откройте `index.html` в браузере либо запустите статический сервер в корне проекта:

```sh
python3 -m http.server 8000
```

После этого адрес: `http://localhost:8000`.

Автотесты расчётного ядра (Node.js 18+):

```sh
node --test tests/engine.test.cjs
```

Репозиторий можно публиковать на GitHub Pages как статический **прототип**. Это **не делает** хранение данных многопользовательским и безопасным для реальных клиентов.
