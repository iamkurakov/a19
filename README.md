# А19 — расчёт рекламных конструкций

**Версия 0.5. Режим одного менеджера.** Веб-приложение: https://iamkurakov.github.io/a19/

## Назначение

Перенос исходной модели Excel для световых объёмных рекламных конструкций и металлокаркаса в браузерную систему расчёта. Реализованы работа с параметрами и материалами, производственные операции, ручные поправки, сохранение проверочных заказов, диагностика формул.

## Приватная модель и заказы

- Публичный GitHub: `iamkurakov/a19` — только код, оформление, тесты.
- Приватный GitHub: `iamkurakov/a19_data` — исходная модель, реестр заказов и подтверждённые внешние данные.
- После **однократной настройки ограниченного GitHub-токена** в интерфейсе загружается модель `A19_excel_model_PRIVATE.json.gz` из закрытого хранилища. Заказы автоматически записываются отдельными JSON-файлами в `a19_data/orders/` после изменений. Сохраняется локальная резервная копия и очередь отправки.
- Если облако не подключено, можно загрузить локальный файл JSON вручную; заказы хранятся только на устройстве.

### Важная граница безопасности

Входа в саму систему А19 нет. Для доступа к приватному GitHub менеджер **один раз вводит отдельный fine-grained token** только для `a19_data` (Repository permissions → Contents: Read and write). **Никаких токенов в публичном репозитории нет.** Запомненный токен хранится в браузере; это временный компромисс для личного рабочего устройства. См. [правила облака](docs/CLOUD_STORAGE.md).

## Формулы и ошибки

Исходная книга содержит 16 листов и 4 115 формул. На исходном примере 4 025 формул вычисляются, 54 воспроизводят ошибки исходного Excel, 36 зависят от неполных внешних справочников. В системе эти ошибки видны в разделе «Диагностика»; цены и прибыль считаются предварительными и не должны без сверки попадать в утверждённое коммерческое предложение. Автоматические нули вместо неизвестных ставок не подставляются.

## Работа менеджера

1. Открыть сайт и подключить приватную базу (один раз на устройстве). Модель загрузится автоматически.
2. Выбрать раздел расчёта и ввести размеры, количество элементов, материалы и работы. Система пересчитает формулы Excel.
3. При необходимости изменить цену или количество вручную. Сохранить как новый тестовый заказ.
4. После сохранения дождаться статуса «Облако подключено»; проверить заказ в `a19_data/orders/`. При ошибке сделать локальную резервную копию.
5. Исправлять недостающие справочники только по подтверждённой информации заказчика; неизвестные формулы не исправлять на глаз.

## Разработка

- `src/excel.js` — интерпретатор исходных формул, без `eval`.
- `src/excel-ui.js` — расчёт, листы Excel, диагностика.
- `src/app.js` — заказы, локальное резервное копирование, мост с расчётным модулем.
- `src/cloud.js` — приватный GitHub API, ограниченные пути записи, очередь автосохранения и проверка конфликтов.
- `tests/*` — расчётные тесты и проверка облачного протокола.
- `docs/EXCEL_ERRORS.md`, `docs/EXCEL_FIDELITY.md` — диагностика.

Локально: `node --test tests/*.test.cjs`.

«Идеал Потолок» (`ideal_potolok`, `ideal_potolok_data`) остаётся полностью независимым проектом, только чтение при аудите. Исходники, заказы и секреты предыдущего проекта не копируются в А19.
