# А19 — расчёт рекламных конструкций

Версия 0.2, отдельное приложение одного менеджера без регистрации и пароля. Публикация через GitHub Pages, ветка `main`, папка `/`.

## Режимы

- **Калькулятор Excel** — новый интерфейс для 16 листов исходного калькулятора лицевого свечения на металлокаркасе. Использует интерпретатор 4 115 формул Excel, связи между листами, таблицы, именованные диапазоны, внешние ссылки и сохранённые значения внешнего справочника. При изменении ячейки пересчитывает зависящие от неё результаты. Поддерживает ручное переопределение вычисляемых значений и возврат к формуле.
- **Заказы / черновики** — прежний упрощённый калькулятор версии 0.1, пока не связан с Excel-моделью и не годится для утверждения производственных смет.
- **Справочник** — прежний локальный справочник версии 0.1, также пока не связан с Excel-моделью.

## Исходная формульная модель и приватность

**Реальные цены, закупки и производственные нормы намеренно НЕ включены в публичный репозиторий.** В браузере менеджер импортирует локальный файл `A19_excel_model_PRIVATE.json`, полученный из исходного `.xlsx` скриптом `tools/export_excel_model.py`:

```bash
python3 tools/export_excel_model.py "Калькулятор.xlsx" "A19_excel_model_PRIVATE.json"
```

Файл JSON содержит исходные значения и все формулы, его необходимо хранить как конфиденциальный. Не коммитить его в `a19`. В интерфейсе «Калькулятор Excel» нажать «Загрузить расчётную модель» и выбрать этот файл. Данные сохраняются **только в IndexedDB браузера**. «Резервная копия модели» выгружает JSON со всеми ручными переопределениями. При очистке данных браузера без резервной копии изменения могут быть потеряны.

**Проверка исходной книги (18.11.2026):** из 4 115 формул 4 067 вычисляются без ошибки; 48 возвращают исходные ошибки либо неразрешённые внешние значения, в том числе отсутствующие записи по сотрудникам. Для успешно вычисленных числовых результатов базового примера расхождений с числовым кэшем Excel не найдено. Это не заменяет проверку сценариев и не гарантирует равенство во всех режимах Excel. 54 формулы исходной книги имеют сохранённые значения ошибок.

## Ограничения

- Интерпретатор не является заменой Excel как программы: неподтверждённые ссылки/значения показаны ошибками. Следует проверять производственные сценарии и фактические нормы.
- **Закрытого GitHub-репозитория и облачной синхронизации пока нет.** Текущий проект не содержит и не должен содержать GitHub PAT, пароли или рабочие данные. Статический GitHub Pages без сервера не может безопасно хранить токен с правом записи в закрытый репозиторий.
- `a19.group` не удалось прочитать через доступные источники, поэтому точное соответствие его шрифтам, анимациям, кнопкам и сетке пока не подтверждено. Использован оригинальный SVG-логотип А19 и нейтральные монохромные элементы.
- Прежде чем пользоваться коммерческими расчётами, необходимо устранить все критические ошибки Excel и сверить результат с эталонными заказами.

## Изоляция от «Идеал Потолок»

А19 не импортирует его код, не обращается к GitHub API исходной системы и не использует её заказы, настройки, токены или пароли. Оба репозитория `iamkurakov/ideal_potolok` и `iamkurakov/ideal_potolok_data` служат только документированным архитектурным референсом и не редактируются.
