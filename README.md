# А19 — рабочее пространство менеджера по расчёту рекламных конструкций

Версия 0.4, отдельное приложение одного менеджера без регистрации и пароля. Публикация через GitHub Pages из `main`.

## Расчёты

- Новые расчёты делаются только на основе исходной Excel-модели; старый упрощённый режим сохранён как архив ранее созданных заказов, но больше не используется для новых.
- 16 листов, 4 115 формул, таблицы, связи между листами и ручные корректировки. Формула остаётся в модели; значения можно переопределить вручную и восстановить.
- Сохранение отдельного расчёта как заказа, повторное открытие и изменение, хранение текущего заказа в локальном браузере.
- Отдельный экран диагностики: все ошибки с адресами ячеек, выгрузка CSV, ручное заполнение отсутствующих записей внешнего справочника из подтверждённого источника.
- Кнопка «КП для проверки» формирует только **предварительный внутренний документ**, не утверждённую коммерческую смету.

## Данные и резервная копия

Исходный файл `A19_excel_model_PRIVATE.json` не публикуется в GitHub — он содержит реальные цены и нормы. Его менеджер загружает через браузер. Расчётная модель хранится в IndexedDB, заказы — в localStorage.

**Верхняя кнопка «Скачать резервную копию» создаёт общий `A19_FULL_BACKUP_*.json`, в который входят и модель, и заказы.** Это конфиденциальный файл. Восстановление из полного файла заменяет оба набора данных; до восстановления обязательно сохранить другую копию. Поддерживается импорт старой резервной копии заказов версии 0.2.

Облачной синхронизации и закрытого репозитория данных пока нет. Эти операции не следует имитировать хранением PAT в публичном JavaScript или GitHub Pages. До появления безопасного серверного хранения данные остаются на одном устройстве и могут быть утрачены без резервной копии.

## Контроль формул

При повторном аудите исходной книги 18.11.2026: **4 025 из 4 115 формул** вычисляются, **54 ошибки** содержатся в самой Excel-книге, а ещё **36 формул** не получают данные из внешнего источника. Подробнее — [docs/EXCEL_ERRORS.md](docs/EXCEL_ERRORS.md). Это не 90 независимых дефектов. Приоритет — восстановление внешнего справочника и сверка контрольных заказов. До этого производственную эквивалентность нельзя считать подтверждённой.

## Изоляция

А19 не импортирует данные и секреты «Идеал Потолок» и не записывает файлы в `ideal_potolok` и `ideal_potolok_data`. Они используются исключительно как референс архитектуры.

## Тесты

```bash
node --test tests/*.cjs
```

При версии 0.4 запускаются 13 автоматических тестов, включая проверку сохранения формул при ручных правках, корректное распространение ошибок и ручное заполнение внешних ссылок.

## Дизайн

Интерфейс переработан в единой монохромной системе с типографикой Manrope, обновлёнными формами, кнопками, скруглениями и адаптивной навигацией. Используется переданный SVG-логотип А19. Точное соответствие сайту `a19.group` пока не подтверждено: сайт не удалось получить через доступные источники. Оно не должно заявляться как реализованное.
